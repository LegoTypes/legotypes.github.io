OPNsense plugins

LegoTypes

Tools for home networks and home automation. Signed OPNsense packages from the LegoTypes repository, installed and updated in System > Firmware like any other plugin.

  • WireGuard Upstream Tunnels

    os-wg-client-tunnels · VPN > WireGuard

    Builds, enforces and maintains policy-routed WireGuard VPN upstreams from a provider's config file, in one dialog: WAN pins, MSS clamp, default-route exclusion and health tracking included.

    DetailsSource

  • WAN Failover

    os-wan-failover · System > Gateways

    Holds a lossy WAN out of service until it is clean, moves connections to the right WAN both ways, and restarts Tailscale only when the default route really changed.

    DetailsSource

  • Unbound Upstream via Gateway

    os-unbound-upstream · Services > Unbound DNS

    Sends Unbound's lookups to a resolver inside your VPN tunnels through a gateway group's best member, falls back when none is up, and can fail closed for chosen clients instead.

    DetailsSource

  • MAC Alias Cache

    os-mac-alias-cache · Firewall > Diagnostics

    See what each MAC firewall alias really resolves to, and rebuild them from current host discovery on demand instead of waiting hours for stale addresses to expire.

    DetailsSource

Get started

Check the signing key, then a few commands on the firewall add the signed repository; the plugins then appear in System > Firmware > Plugins.
