LegoTypes

Tools for home networks and home automation. Signed OPNsense packages from the LegoTypes repository, installed and updated in System > Firmware like any other plugin.

  • WireGuard Upstream Tunnels

    os-wg-client-tunnels · VPN > WireGuard

    Builds, enforces and maintains policy-routed WireGuard VPN upstreams from a provider's config file, in one dialog: WAN pins, MSS clamp, default-route exclusion and health tracking included.

    DetailsSource

  • Avahi mDNS Reflector

    os-avahi-reflector · Services

    Bonjour, AirPlay, AirPrint, HomeKit and Matter discovery across VLANs, with full mDNS and DNS-SD reflection instead of raw packet repeating.

    DetailsSource

  • MAC Alias Cache

    os-mac-alias-cache · Firewall > Diagnostics

    See what each MAC firewall alias really resolves to, and rebuild them from current host discovery on demand instead of waiting hours for stale addresses to expire.

    DetailsSource

Get started

One command on the firewall adds the signed repository; the plugins then appear in System > Firmware > Plugins.

pkg add https://legotypes.github.io/opnsense-repo/os-legotypes.pkg && \
  pkg install -fy -r LegoTypes os-legotypes && \
  /usr/local/opnsense/scripts/firmware/register.php install os-legotypes
